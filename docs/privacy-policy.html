1. Overview & Key Facts

STAR Launcher is an Android launcher for Minecraft: Java Edition, including support for managing Java runtimes, graphics renderers, mods, modpacks, shader packs, optional Live Lyrics display, and an optional local Bedrock/Java server bridge (GeyserMC / PaperMC).

Summary: STAR Launcher does not operate a developer telemetry server, does not include third-party advertising or analytics SDKs, and does not automatically upload crash reports. However, the app stores account credentials, device hardware diagnostics, and launcher settings locally on your device, and connects directly to third-party APIs when you sign in, download game assets, browse mods/modpacks, look up lyrics, or join servers.

2. Data Accessed & Stored on Your Device

Depending on the features you use, STAR Launcher accesses and stores the following categories of information locally on your device:

2.1 Account & Authentication Data

  • Microsoft / Minecraft Java Accounts: When you sign in with Microsoft, STAR Launcher receives your Microsoft OAuth refresh token, Xbox Live / XSTS tokens (including XUID), Minecraft Java access token, Minecraft profile username, and profile UUID. WebView cookies, cache, history, and form data are cleared before starting Microsoft sign-in.
  • Offline / Local Profiles: If you create a local offline profile, STAR Launcher stores only the username you enter (3–16 characters) locally without sending it to authentication servers.
  • Profile Skin Avatars: For Microsoft accounts, STAR Launcher caches a local copy of your Minecraft skin head image.

2.2 Device & Hardware Compatibility Information

  • Hardware Capability Snapshot: To determine compatible OpenGL ES / Vulkan renderers and display compatibility status, STAR Launcher reads your device’s CPU architecture (ABI, 64-bit support, core count, max CPU frequency, SoC/hardware model), total and available RAM, Android API level, OpenGL ES vendor/renderer/version, Vulkan hardware version, Adreno KGSL node presence, screen resolution/refresh rates, and thermal sensor readings.
  • Local Device Fingerprint: STAR Launcher computes a local SHA-256 hash derived solely from your primary CPU ABI, Android API level, GPU vendor, GPU renderer string, and Vulkan version. It does not collect Android Advertising ID, ANDROID_ID, IMEI, phone number, MAC address, or precise location.

2.3 Game Instances, Mods, Modpacks & Shaders

  • Launcher & Instance Data: Instance names, Minecraft versions, mod loader selections, JVM memory settings, control layouts, custom UI themes, background media references, and installed mod metadata (stored in a local SQLite Room database aether_launcher.db and app storage).
  • Modpack Imports: When you select a .zip (CurseForge) or .mrpack (Modrinth) archive via Android’s file picker, STAR Launcher reads the archive locally, validates paths, and downloads referenced mod files if required by the modpack manifest.
  • Shader Pack Management: Shader pack operations scan, validate, import, enable/disable, and delete files strictly inside your selected instance’s shaderpacks/ folder on-device. Shader management itself makes no network requests.
  • Optional CurseForge Credentials: If you configure a CurseForge developer API key or a custom CurseForge backend proxy URL and client token, the proxy URL is saved locally in preferences/database and secrets are encrypted in the local Token Vault.

2.4 Live Lyrics & Local Music Player (Optional)

  • External Media Session Metadata: If you enable STAR Live Lyrics and grant Notification Access, STAR Launcher uses Android’s MediaSessionManager solely to read the active media player’s song title, artist, album, duration, playback position, album artwork, and media app name/package so lyrics can be synchronized on screen.
  • Local Playlists & Custom Lyrics: If you add local audio files or custom .lrc files, STAR Launcher stores file URIs, extracted audio tags, cached album thumbnails, and lyrics files locally inside app storage.

2.5 Bedrock Bridge & Local Server Hosting (Optional)

  • Server Profiles & LAN Addresses: If you use STAR Bedrock Bridge, STAR Launcher stores server profiles (names, hosts, ports, icons, auth modes) locally in Room, reads local Wi-Fi/LAN IPv4 and IPv6 interface addresses to display local connection endpoints on screen, and can ping user-specified Minecraft Java/Bedrock server addresses.
  • Floodgate Keys: If you enable Floodgate authentication, its cryptographic key.pem is stored locally and backed up in the encrypted Token Vault.

2.6 Logs, Performance Metrics & Crash Reports

  • Runtime & Crash Logs: STAR Launcher records launcher logs, game launch session records, and unhandled crash stack traces (latestcrash.txt and up to 20 files in crash-reports/) locally on your device. Crash reports include device product/model, supported ABIs, Android version, launcher version, renderer, memory allocation, and stack traces.
  • Local Performance Profiling: Built-in startup and frame-time trackers measure performance locally on your device (and display an optional debug-only overlay). Nothing is transmitted to any remote server.

3. Android Permissions & Why We Request Them

Permission Requirement Purpose & Scope
INTERNET & ACCESS_NETWORK_STATE Required Sign in with Microsoft, download Minecraft/mod loader/runtime files, browse/download mods & modpacks, fetch optional lyrics, download optional bridge servers, and connect to multiplayer servers.
RECORD_AUDIO Optional (Runtime) Requested only if you grant microphone access for in-game voice chat mods (such as Simple Voice Chat) running inside Minecraft. STAR Launcher itself does not record, store, or transmit microphone audio.
BIND_NOTIFICATION_LISTENER_SERVICE Optional (User Setting) Used only when you enable external media detection for STAR Live Lyrics so Android permits MediaSessionManager access to the currently playing song. General notifications (messages, alerts, email, etc.) are ignored and never read, logged, stored, or transmitted.
POST_NOTIFICATIONS Optional (Android 13+) Displays foreground progress and active session notifications for game/modpack downloads, background game execution, music playback, and local server/bridge hosting.
FOREGROUND_SERVICE (Data Sync, Media Playback, Special Use) Required for Active Tasks Keeps downloads, the running Minecraft JVM process, optional music playback, and optional local Java/Geyser servers active when switching apps.
READ_EXTERNAL_STORAGE / WRITE_EXTERNAL_STORAGE (Android 9 and below) Legacy Devices Only Reads and writes Minecraft game data, instances, and crash logs on Android API ≤ 28. Android 10+ uses app-scoped storage and Android’s file picker (SAF), plus an optional DocumentsProvider (FolderProvider) for user file access.
VIBRATE Optional Provides tactile haptic feedback for on-screen virtual controls and supported controllers.

4. Third-Party Services & Network Connections

STAR Launcher does not send your data to our own servers because we do not operate a central user tracking or account backend. When you use online features, the app communicates directly with the following third-party services, each governed by its own privacy policy:

  • Microsoft, Xbox Live & Minecraft Services (login.live.com, user.auth.xboxlive.com, xsts.auth.xboxlive.com, api.minecraftservices.com): Used only when you sign in with or refresh a Microsoft account to authenticate and verify Minecraft ownership. See the Microsoft Privacy Statement.
  • Mojang & Official Game/Loader Repositories (piston-meta.mojang.com, resources.download.minecraft.net, libraries.minecraft.net, repo1.maven.org, meta.fabricmc.net, maven.fabricmc.net, meta.quiltmc.org, maven.quiltmc.org, maven.minecraftforge.net, maven.neoforged.net, optifine.net, downloads.betterthanadventure.net, and github.com/AngelAuraMC/angelauramc-openjdk-build): Used to download Minecraft versions, assets, libraries, mod loaders, and OpenJDK runtimes.
  • BMCLAPI Mirror (Optional) (bmclapi2.bangbang93.com): Contacted only if you manually switch the download source preference from Default to BMCLAPI.
  • MCHeads (mc-heads.net): When refreshing a Microsoft-authenticated profile, STAR Launcher requests your Minecraft profile UUID avatar image from mc-heads.net.
  • Modrinth & CurseForge / Custom Proxy (api.modrinth.com, api.curseforge.com, or a user-configured HTTPS proxy): Contacted when you search, browse, or install mods or modpacks with remote dependencies.
  • LRCLIB (Optional) (lrclib.net): When Live Lyrics is enabled and not set to Local-Only mode, STAR Launcher sends only the active track’s title, artist, album, and duration (along with a generic app User-Agent) to look up synchronized or plain lyrics.
  • GeyserMC & PaperMC (Optional) (download.geysermc.org, fill.papermc.io): Contacted only when you download or check updates for GeyserMC, Floodgate, or PaperMC inside Bedrock Bridge.
  • Cosmetica Capes (Optional) (23.95.137.176 / cosmetica.cc): Disabled by default; only used inside Minecraft if you enable the Cosmetica Capes setting.
  • Minecraft Java Edition & Multiplayer Servers: When you launch Minecraft Java Edition, the game itself and any servers or mods you connect to receive standard network traffic (such as your IP address, Minecraft username, UUID, and gameplay data). Bundled default runtime configuration includes Google Public DNS (8.8.8.8 / 8.8.4.4) in resolv.conf for JVM DNS resolution and Minecraft’s default options.txt template (which includes snooperEnabled:true for legacy Minecraft versions that implement Mojang’s snooper).
  • External Links You Tap: Tapping links such as a Discord community invite or this Privacy Policy opens your device’s browser or target app.

5. Analytics, Advertising & Crash Reporting

  • No Advertising SDKs: STAR Launcher contains no ad networks and does not access your Google Advertising ID.
  • No Third-Party Analytics: STAR Launcher does not integrate Firebase Analytics, Google Analytics, Mixpanel, or similar tracking SDKs.
  • User-Controlled Crash & Diagnostic Sharing: Unhandled crashes and diagnostic exports (star-support-*.txt) are saved locally on your device. Before exporting or recording diagnostic logs, STAR Launcher’s SensitiveLogRedactor strips access tokens, refresh tokens, JWTs, bearer headers, API keys, and CLI UUID arguments. Diagnostic files or logs leave your device only if you explicitly tap Share Latest Log or Export Diagnostics and send them through an app of your choice.

6. Data Storage, Security & Backups

  • Hardware-Backed Encryption: Sensitive secrets stored in STAR Launcher’s Token Vault (such as mirrored Microsoft/Minecraft tokens, optional CurseForge API keys/proxy tokens, and Floodgate keys) are encrypted using AES-256-GCM via Android Keystore (aether_token_vault_v1) in noBackupFilesDir.
  • Backup & Transfer Exclusions: Android Auto Backup and Device-to-Device Transfer rules (backup_rules.xml and data_extraction_rules.xml) explicitly exclude account files (accounts/), the encrypted Token Vault (aether_vault/), and the launcher database (aether_launcher.db*).
  • Important Security Note on Account Files: For compatibility with the underlying launcher engine, account profile JSON files in the app’s private accounts/ directory remain on local device storage even after using the “Encrypt Vault” mirror option. Protect your device with a screen lock and avoid sharing raw accounts/ files.
  • Network Transport: Network requests to authentication, game metadata, mod, lyrics, and bridge APIs use HTTPS/TLS (local development proxies may use http://localhost or http://127.0.0.1 only if configured by you).

7. Data Retention & Deletion

Because we do not collect or store your data on developer-controlled servers, retention is controlled locally on your device:

  • Automatic Pruning: Local archived crash reports are capped at the 20 most recent files; older crash files are automatically deleted. In-memory and disk caches (such as mod thumbnails and lyrics caches) are bounded or removable via Android app cache clearing.
  • In-App Deletion Controls: Within STAR Launcher, you can directly delete game instances, installed Minecraft versions, Java runtimes, mods, shader packs, custom UI themes, saved local music tracks/playlists, custom .lrc lyrics, Floodgate keys, and saved CurseForge API/proxy credentials.
  • Account & Full App Data Deletion:
    The current STAR Launcher Settings UI does not include a one-tap “Delete Account” button to erase saved Microsoft or offline account profile files from the dashboard. To permanently delete all locally stored account profiles, Token Vault keys, diagnostic logs, and database records from your device, open your device’s Android Settings → Apps → STAR Launcher → Storage → Clear Storage / Clear Data, or uninstall STAR Launcher.
    To delete your underlying Microsoft or Xbox account data held by Microsoft, visit https://aka.ms/CloseAccount.
