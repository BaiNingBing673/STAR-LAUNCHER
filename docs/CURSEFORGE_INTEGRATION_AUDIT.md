## 2. Key Architectural Decisions From Audit

1. **No Duplicate Instance or Storage Systems**: The Mods tab operates strictly on `GameInstanceEntity` from `InstanceManager` and writes mods exclusively to `<instance.gameDirPath>/mods` (never defaulting to global `.minecraft`).
2. **Safe Legacy Coexistence**: Existing `ModImportAdapter`, `CurseforgeApi.java`, `InstanceContentManager`, `launcher_profiles.json`, and `aether_instances/` structures remain intact.
3. **Zero Bundled Secrets**: The new CurseForge client never reads `R.string.curseforge_api_key` or `BuildConfig`. It uses `CurseForgeCredentialProvider` supporting authenticated backend proxy mode, `TokenVault`-backed runtime developer configuration, or a clean `Unconfigured` UI state.
4. **Non-Destructive Room Migration**: `AetherDatabase` upgrades cleanly from `version = 1` to `version = 2` via `MIGRATION_1_2` with exported schema `2.json` and migration test coverage.
